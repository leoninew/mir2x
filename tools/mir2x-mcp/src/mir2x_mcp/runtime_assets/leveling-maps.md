# 练级地图与怪物参考

本文依据仓库中的地图、自然刷新脚本和怪物记录整理，供游戏 MCP 控制角色时选择练级地点。调研日期为 2026-11-04；地图名与坐标均使用游戏格坐标。源码链接使用仓库相对路径并带行号，MCP 纯文本阅读时可据链接中的文件路径与 `#L` 行号定位依据。

**源码规则不等于当前活实体。** 刷新区域只说明配置允许在哪里生成怪物，不能证明该位置此刻有怪、道路可通行或怪物仍存活。实际操作须使用当前 `game_get_session`、`game_get_state`、`game_list_nearby` 和必要的 `game_get_map_region` 重新观察，按返回的目标 handle 提交动作，再查询 `game_get_operation` 终态。名字、源码坐标或过往 handle 不能替代当前目标身份。

## 1 级到 2 级的执行路线

本节以道馆低等级角色通过基础战斗从 1 级升到 2 级为规划示例。实际执行前重新读取当前等级、血量和装备，不将示例阶段当作当前角色状态或其他角色的默认属性。

1. 在道馆南门附近确认当前角色、血量、装备和控制状态。南门两名大刀卫士的固定站位为 `(414,166)`、`(417,163)`，见[道馆守卫配置](../../../../../server/script/map/道馆_1.lua#L5)；这些站位可用于辨认出口附近区域，不替代当前可走路径。
2. 沿实际可走道路向南离开城门，先寻找同一张 `道馆_1` 地图上的 **x413–450、y188–225** 区域。这里配置了鸡、猪、牛的自然刷新；不需要先走传送点换地图。该区域是寻怪目的地，本文没有把中途任意格子声明为已验证路径。
3. 用新鲜视野逐个选择鸡、猪或牛。鸡血量最低，猪、牛也属于当前阶段可尝试的基础目标。优先攻击真实可见、可接近的单只；普通路径因建筑、障碍或移动目标而失败时，按终态重新观察并规划，不把失败直接归因为客户端缺陷，也不把目标消失算作击杀。
4. 离开门卫攻击范围后作战，避免将怪物引回门卫。若基础怪物不足或收益偏低，可继续向南寻找 **x413–450、y263–300** 的多钩猫、钉耙猫、稻草人和蛤蟆。它们的基础经验与血量比通常高于牛，但攻击力也更高；先以实际伤害和掉血检验选择。
5. 每次操作结束后重新观察角色和附近怪物。以 `game_get_state` 的实际 `level` 增长确认升级，不以死亡数量、基础经验表或预测经验代替。

等级总经验公式为：0 级是 0；其余等级为 `100L³ + 100L² + 100L + 1000`，见[等级经验函数](../../../../../common/src/sysconst.hpp#L197)。因此达到 1、2、3 级的总经验分别是 1300、2400、4900。刚进入 1 级到 2 级约需再获得 1100 经验，但角色进入 1 级时可能已有溢出经验，不能据此断言当前剩余精确值。

## 道馆附近的自然刷新区域

`loc` 中的 `x/y` 是矩形起点，`w/h` 是宽高。地图脚本调用普通 `randGLoc(x,y,w,h)` 在区域内选有效地面，见[区域统计与随机格绑定](../../../../../server/src/servermap.cpp#L850)和[生成器调用](../../../../../server/script/map/addmonster.lua#L102)。例如 `(413,188,38,38)` 对应整数格 x413–450、y188–225。

更远的普通半兽人主要配置在地图南部较大范围，例如 `(413,488,38,38)`，见[半兽人区域](../../../../../server/script/map/道馆_1.lua#L27)。当前 1→2 阶段没有必要为它跨越整张地图。

## 守卫与经验归属

大刀卫士不是练级目标。其记录为 HP9999、极高防御以及 `INT_MAX` 物攻，见[守卫记录](../../../../../common/src/monsterrecord.inc#L914)。它会主动选取敌人，邻格攻击或跳攻；普通非中立怪物可被其视为敌人，见[守卫 AI](../../../../../server/src/serverguard.cpp#L26)和[敌友判断](../../../../../server/src/serverguard.cpp#L77)。鸡在记录中明确为中立；不要把这一点推广到所有基础怪。

怪物死亡时，服务器按有效攻击者累计伤害占总伤害的比例分配基础经验，见[经验分配](../../../../../server/src/monster.cpp#L1344)，其中每份取四舍五入后的比例值并设最小值 1。攻击记录还有 120 秒有效窗口。因而门卫或其他角色参与伤害时，即使本角色曾攻击并观察到该怪死亡，也不能声称获得完整基础经验或独占击杀。当前角色实际等级增长是最终可观察证据。

## 换图路线与危险选择

离开道馆城墙与切换地图是两回事。南门附近出城仍在 `道馆_1`，能先完成基础练级。以下仅为源码中的触发格和落点，不是已验证的整段可走路线。

| 当前地图触发格 | 目标地图与落点 | 对当前阶段的意义 | 源码 |
| --- | --- | --- | --- |
| 道馆 `(513,583)`、`(514,582)`、`(515,581)`、`(516,580)` | 比奇县，分别 `(207,53)`、`(208,52)`、`(209,51)`、`(210,50)` | 路程远，1→2 无需为换地图专程前往 | [比奇连接](../../../../../common/src/maprecord.inc#L193) |
| 道馆 `(403,30)`、`(404,30)`、`(405,30)` | 灌木林，分别 `(121,467)`、`(122,467)`、`(123,467)` | 不是当前基础练级推荐方向 | [灌木林连接](../../../../../common/src/maprecord.inc#L197) |
| 道馆 `(54,369)`、`(54,370)` | 沃玛神殿入口，分别 `(76,75)`、`(76,74)` | 后续地图入口，当前无需进入 | [沃玛连接](../../../../../common/src/maprecord.inc#L215) |

灌木林配置了天狼蜘蛛、幻影蜘蛛、月魔蜘蛛、独眼蜘蛛和首领，见[灌木林生成脚本](../../../../../server/script/map/灌木林_12.lua#L5)。不能因为它离北门近，就把它当作鸡猪牛野外的同级替代。

天然洞穴、半兽洞穴等后续地图配置洞蛆、蝎子、骷髅、骷髅战士和骷髅精灵，见[天然洞穴一层](../../../../../server/script/map/天然洞穴1层_D011.lua#L5)和[半兽洞穴一层](../../../../../server/script/map/半兽洞穴1层_D001.lua#L5)。本文未验证当前角色在那里作战的能力，也不据地图名称硬分配适合等级。

正常换图发生后，须重新读 session、角色身份、生命状态和新 context；沿当前授权语义恢复控制并重新规划。不能用旧地图坐标、旧目标 handle 或被加载取消的动作继续提交，也不以 GM 传送、修改数据库或经验替代正常路径。
