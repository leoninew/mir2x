# 练级参考索引

练级前先结合当前角色状态选择阶段，再查所需主题：

| 主题 | MCP 知识资源 | 文档 |
| --- | --- | --- |
| 地图、自然怪物、城门与经验归属 | [地图与怪物](mir2x://knowledge/leveling/maps) | [地图参考](leveling-maps.md) |
| 衣饰、武器、商店与穿戴确认 | [装备](mir2x://knowledge/leveling/equipment) | [装备参考](leveling-equipment.md) |
| 技能条件、秘籍学习与经验曲线 | [技能](mir2x://knowledge/leveling/skills) | [技能参考](leveling-skills.md) |

这四个 `text/markdown` 知识资源随 MCP 包提供，读取时不连接游戏，不要求角色在线；它们是当前源码规则的参考，不是实时角色、怪物、路径、库存或商店报价。

实际练级先读取 `game_get_session` 核对实例、角色、能力与当前 context，再读取角色等级和血量、背包装备与已学技能。依据这些实时结果选择地点、目标、装备和技能；用当前视野中的目标 handle 执行动作，并查询 `game_get_operation` 的真实终态。操作后重新观察，以实际等级增长确认升级。

低等级角色可先用已有基础装备普通攻击；达到后续装备或技能的正常门槛，再安排相应获取和学习。不把更换装备、学习尚未到等级的技能或长途换图变为每次战斗的前置条件。具体规则和源码依据见三个主题文档。

静态规则不扩展当前授权或冻结策略，也不能证明某次击杀归属、经验收益、物品获得或技能学习。未知及未确认事实仍须保留，不因查阅文档而重放请求。练级通过正常游戏路径推进，不使用 GM、模拟键鼠、数据库、经验或坐标修改。

主题文档的源码链接以仓库根为定位依据并附 `#L` 行号。发行目录不包含完整 C++/Lua 源码；离线阅读时可据链接中的文件路径和行号在匹配源码版本中核对。
