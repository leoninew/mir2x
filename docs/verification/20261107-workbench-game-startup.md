## Risks and incomplete items / 风险与未完成项

- 旧版启动且未留下注册表的进程不能安全补认；需要由用户自行关闭后，从更新后的 Workbench 启动，之后才能跨会话恢复。
- 多个 Workbench 同时写同一注册表没有新增并发保证；权限或磁盘写入失败按错误状态阻止不安全控制。
- 安装期间已有日志追加了 14:59:38、14:59:42 的桌面启动失败记录（WinError 10048，地址占用）；日志是动态文件，不能声称 hash 未变。安装脚本明确排除日志。用户随后确认关闭开发服务器即可启动；本次补充将端口占用转换为可读启动错误，并在 frozen Windows 程序中弹出系统错误框，显示占用地址、处理建议和日志路径。
- 独立服务端任务新增的无配置启动保护已构建、测试并提交，但没有在本轮重复安装；原始保留玩法快照的修复已有安装和用户实测记录。
- 未现场验证真实游戏窗口、加密 NPC 或重开后的真实游戏交互；代码及恢复/停止路径由自动化覆盖。不改用户存档，不发送游戏命令。
