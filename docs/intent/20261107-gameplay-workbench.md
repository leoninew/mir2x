# Intent / 意图：玩法倍率与工作台优化
最后修改时间: 2026-11-07 08:51:06

## 审查状态与来源

Accepted。合并原 `20261107-gameplay-multipliers.md`、`20261107-workbench-layout.md` 的意图记录，并纳入用户追加的配置修复、Make 命令和 profile 要求；计划与验证使用同名记录。

## 背景与目标

添加独立持久化的经验、金币、掉率全局倍率，默认均为 1，接受有限非负小数及 0，与已有实际生效倍率相乘。工作台从拥挤单页拆为运行、玩法和管理页面，保留草稿与既有保存安全行为。同时修复开发后端的嵌套配置校验错误，统一开发和制品命令。

## 场景与验收

- A01：独立 `multipliers.json` 和工作台“全局倍率”页面；初始值均为 1，旧目录缺文件时按 1 读取，首次保存创建文件。
- A02：支持小数及 0。经验 0 不发放击杀经验，金币 0 不掉金币，掉率 0 不掉任何物品；默认保持原行为，与原实际生效倍率叠乘。
- A03：保存校验、版本冲突、原子写入、备份还原和服务端启动校验覆盖新文件；保存不改动基础配置，重启读取新值。
- A04：相关原生/API/UI 检查与构建通过，安装至 `install`；保留已有玩法文件、本地启动配置和用户备份。
- A05：Ardot 提供可核对的编辑页与运行页原型；当前设计文件原有内容保留。
- A06：游戏运行、四类玩法配置、配置备份、迁移记录独立展示；共享侧栏及目录信息；窄屏可访问导航。
- A07：编辑区随窗口高度伸缩，列表拥有主要滚动区域，保存栏有独立空间；经验输入宽度合理，数据不被底栏覆盖。
- A08：编辑器按类型拆组件；跨页面草稿、校验、冲突、备份还原和启动安全提示延续原行为。
- A09：`make webapi` 能加载 `.env.dev` 中新增的 `GAMEPLAY__ROOT` 分支，不再产生 `gameplay.ROOT` 多余字段错误；环境变量仍优先于 dotenv。
- A10：Make 业务入口仅保留 deps、check、test、web、webapi、binary；空目标打印帮助。默认 `profile=dev`，test 为单元测试，web/webapi 启动前后端，binary 打包并安装。`make binary profile=prod` 可覆盖默认选择。始终加载 `config.yaml`，再叠加 `.env.<profile>` 和环境变量；profile 不写入 YAML。

## 非目标与约束

不改旧服务端配置入口、消息协议或旧倍率存储，不启用原来未被消费的 experienceRate；不修改刷怪规则，不做热加载。新增倍率不与基础经验/掉落/刷怪配置混存。配置目录迁移 baseline 保持；本次不执行 Git 暂存或提交。用户要求关闭本次打开的开发服务器，结束验证后不保留这些服务器。

## 工作量、风险与授权

中等规模跨 C++、Python、Vue 的配置契约与 UI 调整，单会话顺序实施，不拆 task。主要风险为零值、概率分母方向、取整溢出、旧目录兼容、切页丢草稿、滚动布局和制品 profile 选择。极端数值需要边界保护；掉率仍沿用原概率分母取整，多节点需同步配置并重启。
