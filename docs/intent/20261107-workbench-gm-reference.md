## 背景与目标

- 已有 `readme/gameplay/gm-commands.md` 从源码梳理聊天命令、客户端 Lua 和服务端 LOCAL Lua。
- 新增“GM 命令”页面，按入口和用途筛选、搜索名称/说明/示例，结构化查看语法、参数、示例、限制和实现位置。
- 保留移动到比奇地图、造物、恢复生命、增加经验等常用示例，支持复制到剪贴板。

## 非目标

- 不发送游戏命令，不增加 GM 权限，不修改 C++、游戏协议或配置计算逻辑。
- 不增加 Python 接口、依赖、在线知识服务或通用代码执行能力。

## 场景与验收

- A01：导航中的“GM 命令”可直接打开，无需绑定服务端配置目录。
- A02：包含全部 12 个已登记 `@` 命令，以及文档中的主要客户端 Lua、LOCAL/ASYNC 服务端 Lua 函数和加金币/地面金币示例；保留参数与作用差异。
- A03：支持按入口、用途及关键词组合筛选；详情包含可复制的完整示例，包括 `比奇县_0`。
- A04：显式保留 `@makeItem` 缺陷、未实现编辑器、权限现状与服务端 Lua 执行模式，不能把显示装备等同于真正授予装备。
- A05：沿用现有 Vue/Tailwind 视觉与响应式布局；类型、lint、前端构建通过，不新增 UI、性能或覆盖率测试。
