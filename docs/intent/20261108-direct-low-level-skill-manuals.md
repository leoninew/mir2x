# Intent / 意图：书店出售低等级技能秘籍
最后修改时间: 2026-11-08 17:08:13

## Review status / 审查状态

Accepted

## Background and goals / 背景与目标

- 普通书店目前只售基本剑术、火球术和治愈术三种普通书；大部分普通书须靠掉落或任务获取，再付费誊抄为秘籍。
- 让角色可以从任一普通技能书店直接购买其职业前期技能对应的可学习秘籍，简化获得技能的步骤。
- 用户接受道士秘籍按原有等级和前置条件学习：幽灵盾的实际前置困魔咒为 27 级，神圣战甲术依赖幽灵盾；其秘籍可上架，但不改变它们的可学习门槛。

## Non-goals / 非目标

- 不修改技能效果、施法逻辑、职业/等级/前置校验或技能记录。
- 不改变物品数据、价格、掉落表、任务奖励或普通书誊抄规则。
- 不将“购买秘籍”等同于“自动学会技能”；角色仍需在背包中使用秘籍。
- 不修改道馆物品展示商人或客户端业务逻辑，不操作运行中的服务器/NPC。

## Scenarios / 场景

- 玩家在五家普通技能书店查看货品，可购买符合目标清单的 `技能名（秘籍）`。
- 基本剑术、火球术、治愈术三本普通书继续出售，以免破坏首技普通书换秘籍任务。
- 玩家使用购买的秘籍时，服务端继续根据角色职业、当前等级与前置技能决定能否学习。

## Acceptance criteria / 验收标准

- A01：五家普通技能书店均销售按技能记录首阶段等级筛选出的 32 本、等级不高于 26 的秘籍，同时保留现有三本普通书。
- A02：新增目录中的所有物品名称均匹配已有秘籍物品记录，价格保持既有值；不新增、更改物品记录。
- A03：秘籍使用仍走现有学习校验；道士幽灵盾和神圣战甲术的前置限制保持原状。
- A04：练级技能文档准确列出五家书店新增秘籍、保留的普通书以及学习限制。
- A05：按用户后续要求先构建并安装到 `install`，再完成相关 Lua 脚本/目录与文档检查；不操作运行中的游戏。

## Workload and decomposition / 工作量与拆分

小范围 Lua 商店库存调整及对应文档同步。四家书店使用共享商店入口，道馆书鬼使用独立对话/售卖入口；两种入口复用一份静态秘籍目录，不复制五份列表。源码测试审查范围覆盖商店目录装配、物品名称与数量、原货品保留；不拆 task。

## Questions and decisions / 问题与决策

- 决策：将首阶段技能记录等级 `<= 26` 的全部技能秘籍上架，共 32 种；按技能职业列货品，不限制购买职业，购买后仍由原服务端学习逻辑把关。
- 决策：五家普通技能书店供货一致，保留三个现有普通首技书。等级/前置导致暂不可学的秘籍仍可购买。
- 尚无未决问题。

## Risks / assumptions / 风险 / 假设

- 秘籍类别和技能记录使用同名关联；商品目录需与技能/秘籍物品记录同步。实施检查会逐项核对 32 个名称和等级。
- NPC Lua 修改在下次相关服务器/NPC 脚本加载后生效；安装仅更新文件，不重启或操作运行中的服务器。
