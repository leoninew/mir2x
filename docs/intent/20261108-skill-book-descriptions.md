# Intent / 意图：技能书显示学习说明
最后修改时间: 2026-11-08 18:02:21

## Review status / 审查状态

Accepted

## Background and goals / 背景与目标

- 用户反馈技能书只有“游戏处于开发阶段，暂无物品描述”，连适用职业也无法判断，要求补上实际说明。
- 为全部 63 种普通技能书及其 63 种秘籍显示职业、等级、前置技能和使用方式，帮助玩家购买和学习。
- 用户追加要求：每个职业的每种技能书再有一句简单明了的技能用途，可参考网上资料后自行概括。为 63 项技能各维护一句说明，普通书和秘籍共用。
- 用户再次反馈一句话过短：全部技能说明扩充为一到两句，除主要作用外，补充适用场景、范围特点或关键代价，保持简洁易读。

## Non-goals / 非目标

- 不修改学习规则、技能效果、书籍价格和库存；用途参考传奇 3 职业技能资料，不引入其他版本的伤害、等级或操作方式。
- 不扩展其他物品的描述或改动 UI 布局，不操作运行中的游戏，不暂存或提交。

## Scenarios / 场景

- 在背包或 NPC 商店查看雷电术秘籍，可以读到法师、16 级、前置霹雳掌、背包使用学习。
- 普通书注明用于教头誊抄，秘籍注明直接在背包使用。
- 幽灵盾等技能额外显示前置链提高后的等级要求；拍卖详情显示相同说明。
- 玩家查看雷电术时，既能知道雷电攻击单个目标，也能了解其适合集中火力；查看治愈术时能理解其用于自身续航和同伴支援。

## Acceptance criteria / 验收标准

- A01：126 种技能书均有实际学习说明，不再使用开发占位语。
- A02：职业、首阶段等级和前置技能来自既有 MagicRecord；前置链等级较高时明确显示。
- A03：普通书与秘籍使用方法不同，背包、商店、拍卖说明一致；其他物品原描述保留。
- A04：完成 client/server 构建、runtime 安装，再运行针对性描述检查；不运行 UI、性能或全量游戏测试。
- A05：战士 13 项、法师 27 项、道士 23 项技能均有简短作用说明和补充信息，126 种书全部展示；文档按职业列出相同文本并保留参考来源。

## Workload and decomposition / 工作量与拆分

共享物品描述入口与技能记录的调整，涉及共享物品对象、拍卖详情和已有描述测试。学习信息使用现有元数据，63 条技能说明各维护一次，不为 126 本书重复配置。单会话完成，不拆 task。

## Questions and decisions / 问题与决策

- 所有三职业技能书都纳入，不仅限于刚上架的 32 本低级秘籍。
- 学习信息来自源码；技能用途参考新浪传奇 3 三职业技能资料并自行概括，按最新反馈扩充到一到两句，来源见技能书文档。资料只用于说明，不据此宣称所有技能的运行时实现已经验收。无未决问题。

## Risks / assumptions / 风险 / 假设

- 修改共享物品接口需要重编依赖它的 client/server；采用开发文档的日常 runtime 安装，复用现有地图资源。
- 显示默认学习条件，不改变服务器已有的学习检查开关。

## User review notes / 用户审查记录

- 用户要求给技能书添加实际说明；沿用前一任务先构建安装、再验证的执行顺序。
- 本轮继续授权补全三职业所有技能的一句话说明。原先已暂存的变更保持原样，新修改不操作 index。
- 本轮延续相同范围，扩充全部 63 条说明，沿用共享显示与针对性检查，不新增测试入口。
