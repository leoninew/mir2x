# 意图：随游戏制品交付开箱即用的运行管理入口

## 审查状态

Accepted。用户要求添加必要 skill 和 Python CLI，启动和管理服务器/客户端，避免长命令和绝对路径，并将配置、简明文档随制品交付；进一步明确首次也不应手工准备策略。授权实施本功能，不包含 Git 提交或修改用户游戏存档。

## 范围与验收

- A01：从仓库或安装目录执行短命令即可启动、查看、停止/重启本工具管理的服务器和客户端，自动设置工作目录、端口与桥接参数。
- A02：默认配置和有限授权策略随包提供，首次无需编辑 JSON/TOML；动作控制仍须在游戏窗口人工开启。
- A03：提供本地 MCP stdio 入口、宿主配置生成/显式注册、诊断与可发现 skill，用户不填写固定绝对路径。
- A04：Windows 安装目录包含独立管理 EXE、配置、策略、skill 和中文速查，复制目录后仍可解析相对路径；保留 Python wheel/sdist。
- A05：PID 复用、并发启动、外部进程占端口、正常关闭/明确强停均有准确行为，不误杀非本工具进程，不打包数据库/凭据。

不改变原游戏协议、35 个角色工具或人工授权规则；不将进程管理能力加入角色 MCP。实际钱物和游戏操作验收继续归原功能未完成清单。
