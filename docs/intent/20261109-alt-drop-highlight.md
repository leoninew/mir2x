# Intent / 意图：Alt 临时高亮掉落与名称
最后修改时间: 2026-11-09 07:55:38

## Review status / 审查状态

Accepted

## Background and goals / 背景与目标

现有“游戏 → 掉落”已支持按物品类型高亮、隐藏；高亮会改变图标和旋转星标的颜色，名称仅在鼠标指向对应格时显示。增加按住 Alt 临时高亮并显示名称的能力，方便查看战斗后的掉落。

## Non-goals / 非目标

- 不改变掉落、拾取和战斗逻辑，不增加自动拾取。
- 不增加持久化配置、协议或服务端改动。
- 不增加 UI、性能、覆盖率测试，不自动启动游戏或提交代码。

## Scenarios / 场景

- 按住左 Alt 或右 Alt，显示当前视野中未隐藏掉落的高亮和名称；松开后恢复原设置。
- 已设置常驻高亮的物品在松开 Alt 后继续高亮；已隐藏的物品保持隐藏。
- 同一格的多件掉落名称纵向排列，名称显示在角色和特效上方、界面窗口下方。
- Alt+Tab 切出窗口时退出临时显示；已有 Alt 快捷键保留。

## Acceptance criteria / 验收标准

- A01：左右 Alt 均能临时高亮未隐藏掉落的图标及星标，并显示名称；释放后恢复原规则。
- A02：同格名称分行排列，有深色底板，正常鼠标悬停仍显示名称。
- A03：名称不被场景角色和特效覆盖，不覆盖设置、聊天等界面窗口。
- A04：临时显示以当前键盘状态和窗口焦点决定，不保存配置；切出窗口不保留锁定状态，原 Alt 快捷键正常保留。
- A05：完成客户端构建及必要已有输入回归，准确记录未进行的实机视觉验证。
- A06：按用户后续要求安装到 `install/`，安装客户端与本次构建产物一致。

## Workload and decomposition / 工作量与拆分

小型客户端显示功能，修改集中在场景绘制和 SDL 窗口焦点查询。单会话实施，不拆分 task；主要风险为名称绘制层级、同格叠字及失焦后的按键残留。

## Questions and decisions / 问题与决策

- 用户在评估后明确要求“开始实现，要显示名称”，随后要求使用 SpecFlow 记录并实现。
- 沿用评估中的建议：尊重隐藏规则，临时叠加高亮，名称同格纵向排列，默认提供按键行为。
- 无待决问题。
