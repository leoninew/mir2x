# 练级参考索引

练级前先结合当前角色状态选择阶段，再查所需主题：

| 主题 | 文档 |
| --- | --- |
| 地图、自然怪物、城门与经验归属 | [地图参考](leveling-maps.md) |
| 衣饰、武器、商店与穿戴确认 | [装备参考](leveling-equipment.md) |
| 技能条件、秘籍学习与经验曲线 | [技能参考](leveling-skills.md) |

本目录的四份 Markdown 是独立的离线资料，迁自 `develop` 的练级知识。它们记录源码规则；实际角色、怪物、路径、库存和商店报价仍须在游戏中确认。

实际练级先确认当前角色等级和血量、背包装备与已学技能。依据这些实时状态选择地点、目标、装备和技能，使用当前视野中的目标。战斗后重新观察，以实际等级增长确认升级。

低等级角色可先用已有基础装备普通攻击；达到后续装备或技能的正常门槛，再安排相应获取和学习。不把更换装备、学习尚未到等级的技能或长途换图变为每次战斗的前置条件。具体规则和源码依据见三个主题文档。

角色死亡时停止普通战斗，通过游戏正常的返回复活点流程恢复。确认地图、位置和生命后，根据实际承伤补装备和药品，再选择能稳定处理的目标。

静态规则不能证明某次击杀归属、经验收益、物品获得或技能学习。练级参考采用正常游戏路径，不将 GM、数据库、经验或坐标修改作为成长路线。

主题文档使用仓库相对源码链接并附 `#L` 行号；行号以 2026-11-05 迁入时的 `main` 为准。后续源码变动时，按链接中的记录名或函数名继续定位。
