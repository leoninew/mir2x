## 当前阶段怎样选

1–6 级先以普通攻击练级，不把学习技能设为升级前置任务。三职业的第一门基础技能均要求 7 级，见 [基本剑术](../../common/src/magicrecord.inc#L444)、[火球术](../../common/src/magicrecord.inc#L324)、[治愈术](../../common/src/magicrecord.inc#L411)。服务端正常学习路径会校验职业和最低等级，见 [学习检查](../../server/src/player.cpp#L2774)。

| 阶段 | 技能安排 | 使用方式与源码依据 |
| --- | --- | --- |
| 1–6 级，三职业 | 继续普攻，积累正常战斗经验 | 首门基础技能的最低等级均为 7，见上述三个技能定义。 |
| 战士 7–10 级 | 学基本剑术后继续普攻 | 这是被动命中加成，已学时 `dcHit += 2`，见 [战斗属性计算](../../common/src/combatnode.cpp#L108)。 |
| 法师 7–10 级 | 学火球术后按实际 MP、冷却和目标情况施法 | [技能定义](../../common/src/magicrecord.inc#L324)要求法师 7 级，配置基础 MP 为 3、冷却为 500ms；[客户端施法分支](../../client/src/processrun.cpp#L2542)将其转换为 `ActionSpell`。 |
| 道士 7 级起 | 学治愈术；8 级起可考虑精神力战法 | [治愈术](../../common/src/magicrecord.inc#L411)要求道士 7 级，有[客户端施法入口](../../client/src/processrun.cpp#L2536)；[精神力战法](../../common/src/magicrecord.inc#L454)要求道士 8 级。 |
| 战士 14 级起 | 再考虑攻杀剑术 | [技能定义](../../common/src/magicrecord.inc#L496)要求战士 14 级且已学基本剑术；[正常任务](../../server/script/quest/攻杀剑术任务.lua#L13)的最低等级同为 14。 |

被动属性计算与主动施法是不同路径。不能仅因技能没有主动施法分支，就认定它没有效果；基本剑术的命中加成由上述战斗属性计算直接应用。

## 普通书到实际学会

学习技能现在有三种入口：从普通书店购买低级秘籍、普通书交教头誊抄、完成专属任务取得秘籍。**普通书本身不能学习**，只有带 `.book.magic` 的 `（秘籍）` 才能用于学习，见 [物品判定](../../common/src/itemrecord.hpp#L228)、[秘籍物品定义](../../common/src/itemrecord.inc#L15350)和 [服务端拒绝直接学习普通书](../../server/src/player.cpp#L2751)。

在背包或商店查看技能书说明，可直接看到技能作用、适用职业、技能等级要求、前置技能和使用方式。若前置链要求更高等级，说明会额外列出“前置链等级要求”；普通书注明交给教头誊抄，秘籍注明在背包中使用。拍卖详情也使用同一份说明。

1. 对于等级不高于 26 的技能，可从五家普通书店直接购买下表所列秘籍，无需收普通书或誊抄费。其他技能仍可从怪物取得普通书后找教头誊抄，或查看对应专属任务。
2. 在背包中使用 `技能名（秘籍）`。默认学习条件是职业、最低等级和前置技能同时满足；购买秘籍不会自动学会。
3. 看到系统提示“恭喜掌握……”并在技能窗口找到技能后，再设置快捷键。学习检查与结果下发见 [consumeBook](../../server/src/player.cpp#L2751)。

三个首技任务仍可作为入门路线：7 级时，把基本剑术普通书交给龙血先生、火球术普通书交给霹雳尊者、治愈术普通书交给清明子，换取对应秘籍。这三个首次交换不收誊抄费，也没有随机失败；仍需交出一本普通书。直接从书店购买秘籍可省去交换步骤。NPC 位置见后文。

## 学会之后怎样施法

以火球术绑定 `Q` 为例：

1. 点击游戏右下角的技能按钮，打开技能窗口。
2. 切到「火」页，把鼠标停在已学会的火球术图标上，直接按 `Q`。图标显示 `Q` 后，绑定完成。
3. 关闭技能窗口、退出聊天输入，把鼠标指向怪物，按 `Q` 施放，无需再点击鼠标。

技能窗口按「火、冰、雷、风、神圣、暗黑、幻影、无」分页；例如治愈术在「神圣」，基本剑术在「无」。有效快捷键是字母 `A–Z`、`0`、`7–9`，`1–6` 用于物品快捷栏，这套绑定不支持 `F1–F12`。同一按键改绑另一技能时，原绑定被替换。绑定会保存到服务端，重新登录后恢复。

| 类型 | 例子 | 使用方法 |
| --- | --- | --- |
| 目标技能 | 火球术、雷电术、施毒术 | 鼠标指向目标，按绑定键。目标技能会保留上次仍存在的施法目标；换目标时重新指向目标按键。 |
| 地面或方向技能 | 火墙、地狱火、疾光电影 | 鼠标指向位置或方向，按绑定键。 |
| 自身或召唤技能 | 魔法盾、隐身术、召唤骷髅、召唤神兽 | 直接按绑定键，目标由客户端设为自身。 |
| 近战技能开关 | 半月弯刀、烈火剑法、翔空剑法、莲月剑法、十方斩 | 按绑定键切换启用状态，再通过近战攻击使用。 |
| 被动技能 | 基本剑术、攻杀剑术、精神力战法 | 无需手动施放，也不能绑定施法快捷键。 |

输入框有焦点时会先接收按键；技能未冷却时会提示“尚未冷却”。绑定与施法代码分别见[悬停图标后按键](../../client/src/gui/skillboard/magiciconbutton.cpp#L90)、[快捷键范围](../../common/src/serdesmsg.hpp#L965)、[施法与目标处理](../../client/src/processrun.cpp#L2470)、[保存绑定](../../server/src/playernet.cpp#L1480)。

当前客户端还有两个明确的快捷键入口缺口：技能窗口将刺杀剑术、野蛮冲撞列为可绑定技能，但 `checkMagicSpell()` 没有这两项的动作分支。遇到这两项绑键无反应时，需要区分施放实现与学习状态。

## 按职业查每种技能书

表格的读法：

- **等级 / 前置**：技能记录中的第一阶段等级及必须已学的前置技能。默认学习检查同时验证两项，前置链可能进一步提高实际可学等级。
- **普通书购买**：只列普通书店；“—”表示这些书店没有在售。展示商人对全部 63 项都适用。
- **普通书掉落**：全量扫描当前 `server/config/gameplay/drops/*.json` 后，63 项均有出处；常规掉落表没有直接掉落 `（秘籍）` 的条目。
- **秘籍任务**：直接奖励对应秘籍的专属任务，链接为任务脚本；“—”表示未找到对应专属秘籍任务，仍可走普通书誊抄。
- **誊抄费**：比奇县对应职业教头收取的金币，另消耗一本普通书。

为避免每行重复长名单，掉落列使用以下固定称呼：

| 表中称呼 | 准确怪物名与掉落配置 |
| --- | --- |
| 僵尸组 | [僧侣僵尸](../../server/config/gameplay/drops/89.json)、[雷电僵尸](../../server/config/gameplay/drops/86.json)，两者掉书清单和基数相同；不包括其他名字的僵尸。 |
| 尸王 | [尸王](../../server/config/gameplay/drops/100.json) |
| 诺玛五种 | [诺玛骑兵](../../server/config/gameplay/drops/346.json)、[诺玛装甲兵](../../server/config/gameplay/drops/348.json)、[诺玛抛石兵](../../server/config/gameplay/drops/350.json)、[诺玛司令](../../server/config/gameplay/drops/352.json)、[诺玛斧兵](../../server/config/gameplay/drops/355.json)，五者掉书清单和基数相同。 |
| 队长 / 教主 | [诺玛突击队长](../../server/config/gameplay/drops/354.json) / [诺玛教主](../../server/config/gameplay/drops/357.json)；表中合写时表示两者都掉，分开写时只适用指定怪物。 |

`1/N` 表示配置基数。这些普通书条目均为组 0、尝试 1 次、数量 1，在服务端掉率与玩法掉落倍率均为 1 时，每条判定为 `1/N`，不是击杀 N 只保底掉一本。运行时倍率会改变分母，倍率为 0 时不掉；见[掉落计算](../../server/src/dropitemconfig.cpp#L25)与[默认玩法倍率](../../server/config/gameplay/multipliers.json)。服务器读取其工作目录中的 `config/gameplay`；若已用 Workbench 修改，以启动时加载的配置为准，旧 `dropitemconfig.inc` 不作为现行掉落依据。

道士有三处容易误判的等级关系：灵魂火符标为 13 级，但前置隐身术为 20 级，因此默认最早 20 级；幽灵盾标为 21 级，却前置 27 级困魔咒，因此最早 27 级；神圣战甲术标为 25 级，又依赖幽灵盾，也要等到至少 27 级。任务可以先发秘籍，不代表当时就满足使用秘籍的条件。

## 等级经验曲线

`SYS_SUMEXP(n)` 表示从 0 级到达 `n` 级的总经验，0 级为 0，其他等级为 `100*n^3 + 100*n^2 + 100*n + 1000`，见 [经验函数](../../common/src/sysconst.hpp#L198)。下面是该公式的直接结果，不是某次战斗的实际经验收益：

| 达到等级 | 总经验门槛 | 从上一等级起点所需 |
| --- | ---: | ---: |
| 1 | 1,300 | 1,300 |
| 2 | 2,400 | 1,100 |
| 3 | 4,900 | 2,500 |
| 4 | 9,400 | 4,500 |
| 5 | 16,500 | 7,100 |
| 6 | 26,800 | 10,300 |
| 7 | 40,900 | 14,100 |
| 8 | 59,400 | 18,500 |
| 9 | 82,900 | 23,500 |
| 10 | 112,000 | 29,100 |

只读到“当前 1 级”不能据此说角色还差整整 1100 经验；角色可能已有本级积累。等级根据实际总经验所在区间计算，见 [等级换算](../../common/src/sysconst.hpp#L215)。应以实际角色等级前后变化验证练级结果。

## 熟练度与可观测边界

技能定义带有多阶段等级及训练配置，例如 [基本剑术](../../common/src/magicrecord.inc#L444)为 `{7,9,11}`，但这不等于当前实现已经完成所有熟练度成长。当前 [SDLearnedMagic](../../common/src/serdesmsg.hpp#L914)虽保存 `exp`，其 `level()` 仍直接返回 1。不能凭配置或攻击次数宣称技能已经升到二、三级。

NPC 说明也可能保留历史数据：道馆书鬼对治愈术的说明为 7/11/16，见 [对话](../../server/script/npc/道馆_1.书鬼_1.GLOC_418_96_0.LOOK_18.lua#L67)，而当前 [技能定义](../../common/src/magicrecord.inc#L411)为 7/9/11。规划时区分对话文案、服务端执行条件和当次角色实际观察；不以旧台词或静态配置替代已学状态。
