# 练级阶段与技能参考

本页根据当前仓库源码整理正常技能成长路线。源码中的学习条件、NPC 位置和物品定义用于选择下一步；角色是否已学、能否施放及是否升级，仍以当次游戏观察为准。客户端通过 [SM_LEARNEDMAGICLIST](../../client/src/processrunnet.cpp#L124)更新已学技能。

全部职业技能的等级、前置、普通书/秘籍区别和通用教头誊抄流程见[技能与技能书](skills-and-books.md)。

## 当前阶段怎样选

1–6 级先以普通攻击练级，不把学习技能设为升级前置任务。三职业的第一门基础技能均要求 7 级，见 [基本剑术](../../common/src/magicrecord.inc#L438)、[火球术](../../common/src/magicrecord.inc#L321)、[治愈术](../../common/src/magicrecord.inc#L406)。服务端正常学习路径会校验职业和最低等级，见 [学习检查](../../server/src/player.cpp#L2774)。

| 阶段 | 技能安排 | 使用方式与源码依据 |
| --- | --- | --- |
| 1–6 级，三职业 | 继续普攻，积累正常战斗经验 | 首门基础技能的最低等级均为 7，见上述三个技能定义。 |
| 战士 7–10 级 | 学基本剑术后继续普攻 | 这是被动命中加成，已学时 `dcHit += 2`，见 [战斗属性计算](../../common/src/combatnode.cpp#L108)。 |
| 法师 7–10 级 | 学火球术后按实际 MP、冷却和目标情况施法 | [技能定义](../../common/src/magicrecord.inc#L321)要求法师 7 级，配置基础 MP 为 3、冷却为 500ms；[客户端施法分支](../../client/src/processrun.cpp#L2510)将其转换为 `ActionSpell`。 |
| 道士 7 级起 | 学治愈术；8 级起可考虑精神力战法 | [治愈术](../../common/src/magicrecord.inc#L406)要求道士 7 级，有[客户端施法入口](../../client/src/processrun.cpp#L2504)；[精神力战法](../../common/src/magicrecord.inc#L447)要求道士 8 级。 |
| 战士 14 级起 | 再考虑攻杀剑术 | [技能定义](../../common/src/magicrecord.inc#L487)要求战士 14 级且已学基本剑术；[正常任务](../../server/script/quest/攻杀剑术任务.lua#L13)的最低等级同为 14。 |

被动属性计算与主动施法是不同路径。不能仅因技能没有主动施法分支，就认定它没有效果；基本剑术的命中加成由上述战斗属性计算直接应用。

## 普通书到实际学会

正常顺序为“获得普通技能书 → 教头誊抄为秘籍 → 使用秘籍 → 确认已学技能”。普通技能书本身是原料，只有带 `.book.magic` 的秘籍才能用于学习，见 [物品判定](../../common/src/itemrecord.hpp#L228)、[秘籍物品定义](../../common/src/itemrecord.inc#L15350)和 [服务端拒绝直接学习普通书](../../server/src/player.cpp#L2751)。

实际操作时逐步确认：

1. 从正常商店、任务或掉落取得所需普通书，确认背包中的具体物品实例。基本剑术普通书定义见 [物品记录](../../common/src/itemrecord.inc#L1568)，一个正常售书 NPC 见 [老余货物列表](../../server/script/npc/边境城市_01.老余_1.GLOC_445_319_0.LOOK_2.lua#L13)。
2. 读取真实 NPC 对话，再走对应任务或誊抄选项。基础战士任务会检查职业、等级和普通书，见 [任务条件](../../server/script/quest/基本剑术任务.lua#L40)；通用誊抄另有金币及物品消耗，见下一节。
3. 取得秘籍后，通过游戏背包正常使用，逐本确认学习结果。
4. 查看背包与技能界面。服务端通过学习检查后才加入已学列表并下发 `SM_LEARNEDMAGICLIST`，见 [学习结果](../../server/src/player.cpp#L2806)。物品减少本身不能替代“技能已出现”的确认。
5. 主动技能还须检查当前 MP、目标与冷却；客户端从技能快捷键进入 [checkMagicSpell](../../client/src/processrun.cpp#L2438)，服务端通过 [onCMActionSpell](../../server/src/player.cpp#L1606)执行后续校验与效果。

当前角色的已学技能以游戏内技能列表为准，不能把静态技能定义当成该角色已经学会。

## 战士首次基本剑术的正常途径

普通书可在边境城市 `老余_1` 处购买。NPC 脚本文件登记的地图为 `边境城市_01`、坐标为 `(445,319)`，货物列表含基本剑术，见 [老余脚本](../../server/script/npc/边境城市_01.老余_1.GLOC_445_319_0.LOOK_2.lua#L1)。[普通书物品记录](../../common/src/itemrecord.inc#L1568)的基础价为 1000；实际交易仍须读取当前商店报价，不能将基础价视为当次购买回执。

7 级且职业为战士时，携带普通基本剑术书找边境城市 `龙血先生_1`，坐标 `(456,302)` 来自 [NPC 文件名登记](../../server/script/npc/边境城市_01.龙血先生_1.GLOC_456_302_0.LOOK_46.lua)；地图加载器按此文件名解析 NPC 坐标，见 [NPC 加载规则](../../server/src/servermap.cpp#L1578)。该 NPC 文件本身为空，首次“基本剑术任务”会向该地图和 NPC 注入任务处理器，最低等级为 7，见 [任务绑定与注入](../../server/script/quest/基本剑术任务.lua#L13)。

这条首次任务先检查尚未完成、尚未学会、职业、等级和持有普通书，见 [准入与对话](../../server/script/quest/基本剑术任务.lua#L40)。最后一步将任务置为完成，移除一份普通书并给予一份基本剑术秘籍；该交换分支没有扣金币或随机失败逻辑，见 [首次任务交换](../../server/script/quest/基本剑术任务.lua#L97)。它仍然消耗普通书，不能省略物品确认；得到秘籍后还要使用并重读技能列表。

其他职业的首技也有正常首次任务：法师的 [火球术任务](../../server/script/quest/火球术任务.lua#L12)绑定银杏山谷 `霹雳尊者_1`，道士的 [治愈术任务](../../server/script/quest/治愈术任务.lua#L9)绑定 `本馆_1_002` 的 `清明子_1`。这些是后续达到相应职业及等级条件时的参考，不是当前低等级练级必须先完成的事项。

## 通用教头誊抄有消耗与失败概率

通用 `skillteacher` 与上述首次任务不是同一分支。它会先收金币，再移除普通书；随后以 `math.random(20) == 1` 判定誊抄失败，失败时金币和书均不会退回，见 [失败分母](../../server/script/npc/include/skillteacher.lua#L36)与 [收取及誊抄流程](../../server/script/npc/include/skillteacher.lua#L161)。成功才给予对应秘籍，见 [成功奖励](../../server/script/npc/include/skillteacher.lua#L192)。

因此，选择这种 NPC 脚本选项前应报告实际费用、消耗的一份普通书和可能失败的结果，不能将其当作无副作用的“开关对话”。各教头价格由其脚本配置；例如清明子的普通誊抄列表中，治愈术为 700、精神力战法为 800，见 [清明子配置](../../server/script/npc/本馆_1_002.清明子_1.GLOC_11_10_0.LOOK_14.lua#L23)。

## 等级经验曲线

`SYS_SUMEXP(n)` 表示从 0 级到达 `n` 级的总经验，0 级为 0，其他等级为 `100*n^3 + 100*n^2 + 100*n + 1000`，见 [经验函数](../../common/src/sysconst.hpp#L198)。下面是该公式的直接结果，不是某次战斗的实际经验收益：

| 达到等级 | 总经验门槛 | 从上一等级起点所需 |
| --- | ---: | ---: |
| 1 | 1,300 | 1,300 |
| 2 | 2,400 | 1,100 |
| 3 | 4,900 | 2,500 |
| 4 | 9,400 | 4,500 |
| 5 | 16,500 | 7,100 |
| 6 | 26,800 | 10,300 |
| 7 | 40,900 | 14,100 |
| 8 | 59,400 | 18,500 |
| 9 | 82,900 | 23,500 |
| 10 | 112,000 | 29,100 |

只读到“当前 1 级”不能据此说角色还差整整 1100 经验；角色可能已有本级积累。等级根据实际总经验所在区间计算，见 [等级换算](../../common/src/sysconst.hpp#L215)。应以实际角色等级前后变化验证练级结果。

## 熟练度与可观测边界

技能定义带有多阶段等级及训练配置，例如 [基本剑术](../../common/src/magicrecord.inc#L438)为 `{7,9,11}`，但这不等于当前实现已经完成所有熟练度成长。当前 [SDLearnedMagic](../../common/src/serdesmsg.hpp#L914)虽保存 `exp`，其 `level()` 仍直接返回 1。不能凭配置或攻击次数宣称技能已经升到二、三级。

NPC 说明也可能保留历史数据：道馆书鬼对治愈术的说明为 7/11/16，见 [对话](../../server/script/npc/道馆_1.书鬼_1.GLOC_418_96_0.LOOK_18.lua#L67)，而当前 [技能定义](../../common/src/magicrecord.inc#L406)为 7/9/11。规划时区分对话文案、服务端执行条件和当次角色实际观察；不以旧台词或静态配置替代已学状态。
