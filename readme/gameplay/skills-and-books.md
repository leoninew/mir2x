# 技能与技能书

本文按当前仓库中的技能记录、物品记录和服务端任务整理。静态门槛用于规划，不代表某个角色已经学会；角色技能列表、背包物品及当次 NPC 对话仍以游戏内状态为准。低等级阶段的实用建议见[练级技能路线](leveling-skills.md)。

## 先分清三种东西

| 名称                         | 作用                                                                                                   |
| ---------------------------- | ------------------------------------------------------------------------------------------------------ |
| 普通技能书，例如“基本剑术”   | 原料书。可以通过已确认的书店或怪物掉落取得，但不能直接使用来学技能。                                   |
| 秘籍，例如“基本剑术（秘籍）” | 带有目标技能标记的学习物品。角色满足职业、等级和前置技能要求时，才可使用学习。                         |
| 已学技能                     | 服务端角色记录中的技能。学会后客户端技能栏才显示相应图标；拿到秘籍或看到静态技能记录都不等于已经学会。 |

物品记录中普通书的 `.book.job`、`.book.level` 是物品元数据；实际学习检查读取秘籍关联的技能记录 `MagicRecord::req`。服务端默认检查职业、第一阶段等级和前置技能。三个 `--disable-learn-magic-check-*` 启动选项可以分别关闭对应检查，不应将带有这些选项的服务端状态当作普通默认规则。

## 正常学习流程

### 直接购买低等级秘籍

五家普通技能书店均出售首阶段记录等级不高于 26 的 32 本秘籍：战士 4 本、法师 17 本、道士 11 本，每本基础价 1,000 金币。完整书目见[普通书店秘籍清单](leveling-skills.md#谁卖普通书)。购买后在背包使用，仍须满足职业、等级和前置技能要求；幽灵盾、神圣战甲术的前置链仍使其最早要到 27 级才能学习。

### 首个技能任务

三个职业的首个技能有专门的普通书换秘籍任务，要求相应职业、角色达到 7 级并携带对应普通书。对话任务消耗普通书、给一本秘籍；这条首次任务分支不收取通用教头费用，也没有通用誊抄的随机失败：

| 职业 | 技能     | 任务 NPC   | 地图坐标              | 源码                                                   |
| ---- | -------- | ---------- | --------------------- | ------------------------------------------------------ |
| 战士 | 基本剑术 | 龙血先生_1 | 边境城市_01 (456,302) | [任务](../../server/script/quest/基本剑术任务.lua#L11) |
| 法师 | 火球术   | 霹雳尊者_1 | 银杏山谷_02 (265,145) | [任务](../../server/script/quest/火球术任务.lua#L11)   |
| 道士 | 治愈术   | 清明子_1   | 本馆_1_002 (11,10)    | [任务](../../server/script/quest/治愈术任务.lua#L8)    |

坐标来自 NPC 文件登记，不保证当前地图、NPC 或通路状态。任务需要的普通书可由相应书店购买（下节列出已核对实例），或从怪物掉落获取。对话结束并确认获得秘籍后，还要在背包中使用秘籍，确认服务器接受学习并在技能栏看到技能。

### 通用教头誊抄

普通书也可以交给武功教头誊抄为秘籍。共享流程位于 [`skillteacher.lua`](../../server/script/npc/include/skillteacher.lua#L34)：

1. NPC 菜单按职业显示其脚本配置中的技能和誊抄价格；所展示的等级分组是菜单说明，不是这段通用誊抄处理器的等级门槛。
2. 提交后先检查普通书和金币，随后扣除金币并移除一份普通书。
3. 之后以 `math.random(20) == 1` 判定失败。失败时书和钱都不退；成功才给予对应秘籍。
4. 使用秘籍是另一个独立步骤。此时服务端才检查重复学习、职业、最低等级和 `MagicRecord` 前置技能。

失败概率按脚本表达式为 1/20。先确认当前角色、背包和 NPC 报价；失败或结果不明时先重新查看背包和金币，不要因为对话已结束就假定秘籍到手。

几个可核对的教头实例：

| NPC                 | 地图坐标  | 脚本配置范围                                                                           |
| ------------------- | --------- | -------------------------------------------------------------------------------------- |
| 比奇县_0 总教头_1   | (447,444) | 战士技能，从基本剑术到高等级技能；后段列有 10,000 金币誊抄价                           |
| 比奇县_0 华龙断珠_1 | (462,435) | 法师技能；前段价格约 700–3,500，脚本列出的高等级技能为 10,000                          |
| 比奇县_0 比奇道长_1 | (449,433) | 道士技能；前段价格约 700–3,500，脚本列出的高等级技能为 10,000                          |
| 本馆_1_002 清明子_1 | (11,10)   | 道士技能；配置包含治愈术、精神力战法、施毒术、召唤骷髅、隐身术、集体隐身术、神圣战甲术 |

价格是对应 NPC 脚本的誊抄配置，不是所有教头的统一价，也不是购买普通书的价格。脚本原始价格见[总教头](../../server/script/npc/比奇县_0.总教头_1.GLOC_447_444_0.LOOK_15.lua#L6)、[华龙断珠](../../server/script/npc/比奇县_0.华龙断珠_1.GLOC_462_435_0.LOOK_18.lua#L6)、[比奇道长](../../server/script/npc/比奇县_0.比奇道长_1.GLOC_449_433_0.LOOK_16.lua#L6)和[清明子](../../server/script/npc/本馆_1_002.清明子_1.GLOC_11_10_0.LOOK_14.lua#L6)。

### 使用秘籍学习

背包使用秘籍后，服务端检查：

- 该技能尚未学会；已学技能不能重复学习。
- 职业符合技能记录。
- 角色达到技能记录中的第一阶段等级。
- 技能记录存在前置技能时，角色已学会该前置技能。

检查失败时本次物品不会被消耗；成功时写入角色技能记录、持久化到数据库并向客户端发送已学技能列表。取得秘籍后不应直接假定学习成功，应查看系统提示和技能栏。

## 技能书获取途径

下文的怪物和概率来自仓库现有的 `server/config/gameplay` 配置。服务端启动时读取工作目录下的 `config/gameplay`，Workbench 可以修改这些配置；实际服务器若使用了修改后的文件，以其启动时加载的数据为准。历史文件 `dropitemconfig.inc` 不是当前运行时掉落表。

## 技能等级与实际使用边界

- 技能记录和部分 NPC 说明写有三个阶段等级；但当前 `SDLearnedMagic::level()` 固定返回 1，客户端接收已学列表时也将技能等级设为 1。数据库虽有技能经验字段，当前源码没有普通升级流程调用。不要按等级门槛表推断角色能把技能练到第 2/3 级。
- `MagicReq::train` 字段存在于记录结构中，但当前源码没有使用该字段作为正常技能升级计数。
- 技能栏只显示角色已学技能。已学主动技能可在技能图标上设置快捷键；有效键为 `0`、`7`–`9` 和字母 `a`–`z`，`1`–`6` 保留给快捷栏物品。被动技能不能绑定施法快捷键。基本剑术例如通过战斗属性计算给命中 +2，而不是手动施放，见[战斗属性计算](../../common/src/combatnode.cpp#L108)。
- 主动技能的施法入口和效果由客户端、服务端的具体分支实现。上面的目录整理的是技能定义与学习条件；定义存在或已经学会，都不足以证明该技能的全部效果已实现。施法实现入口见[客户端检查](../../client/src/processrun.cpp#L2438)和[服务端处理](../../server/src/player.cpp#L1606)。
