# 地图连接与路线

本页整理当前源码中的步行换图与 NPC 传送。要查任意两张地图之间的静态连接，可先在[地图连接索引](map-connections.md)搜索当前地图，再沿目标地图继续查；下面另有常见路线示例。地图名称保留 `_0`、`_D401` 等后缀，避免把同名区域或不同副本混淆。

## 如何理解一条连接

地图的 [`switchList`](../../common/src/maprecord.inc#L3) 给出入口格 `(x,y,w,h)`、目标地图及落点。角色走到入口格后，通常会触发换图；矩形范围从 `(x,y)` 开始，宽 `w`、高 `h`。连接是**有方向的**：去程和回程要分别查，不能直接把入口、落点对调。

索引按源码顺序处理了覆盖：同地图同一格有多条有效配置时，后面的配置覆盖前面的配置，见[地图初始化](../../server/src/servermap.cpp#L581)。每个“来源地图 → 目标地图”只展示一个未被覆盖的入口格和它的配置落点；其他入口格及可能不同的落点通过该条链接查看源码。`未命名地图_D601` 这个目标在当前地图记录中不存在，服务器初始化时不会安装该条连接，索引不把它当可用出口。

这是地图级连接，不是逐格寻路结果。它不能证明两个入口之间有可走的地形、地图资源已部署、入口当前未被遮挡或角色能安全通过。任务脚本可以接管入口、检查状态、阻止或改写传送，副本也可能有独立实例；因此即使索引中存在连接，也要以实际地图和任务状态为准，见[格子触发器](../../server/src/servermap.lua#L14)。

## 常用步行路线

下表每步给出**当前地图入口 → 下一地图落点**，选取的是源码中的一组入口格，不是唯一走法。每次换图后再朝下一步的入口前进。

### 道馆到比奇、银杏与废矿

| 路线 | 具体换图步骤 |
| --- | --- |
| 道馆 → 比奇县 | 道馆_1 `(513,583)` → 比奇县_0 `(207,53)` |
| 道馆 → 银杏山谷 | 道馆_1 `(513,583)` → 比奇县_0 `(207,53)`；比奇县_0 `(776,701)` → 银杏山谷_02 `(27,455)` |
| 道馆 → 废矿入口 | 道馆_1 `(513,583)` → 比奇县_0 `(207,53)`；比奇县_0 `(764,206)` → 废矿矿山入口_D401 `(25,181)` |
| 道馆 → 尸王房 | 按上一行到废矿矿山入口_D401；再走 `(80,172)` → 尸王房_D401_001 `(15,15)` |
| 道馆 → 本馆 | 道馆_1 `(429,96)` → 本馆_1_002 `(10,17)`；清明子在本馆 `(11,10)` |

相关地图配置：[道馆](../../common/src/maprecord.inc#L187)、[比奇县](../../common/src/maprecord.inc#L3)、[废矿入口](../../common/src/maprecord.inc#L3009)。废矿也是[僧侣僵尸及尸王技能书](skills-and-books.md#怪物掉落僵尸与尸王)的来源之一。

## 其他入口

- 某些技能任务会通过 NPC 对话或触发器创建独立试炼地图，例如[攻杀剑术试炼](../../server/script/quest/攻杀剑术任务.lua#L58)；不能把它当成公共地图之间的普通出口。
- [困魔咒任务](../../server/script/quest/困魔咒任务.lua#L405)和[群体治愈术任务](../../server/script/quest/群体治愈术任务.lua#L732)会接管指定入口，实际去向及能否进入取决于任务状态。
- 物品记录里有回城卷、地牢逃脱卷等名称，但当前[背包使用处理](../../server/src/playernet.cpp#L1420)只处理书和药水，其他类型尚未实现；不要把卷轴记录当作已确认的传送路线。
- GM 和调试脚本可以进行额外传送，见 [GM 聊天命令](gm-commands.md)；不属于上面的普通步行或神石路线。
